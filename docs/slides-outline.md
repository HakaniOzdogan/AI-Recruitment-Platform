# 10 Slaytlik Sunum Taslagi

## 1) Baslik + Ekip
- Proje adi
- Takim/rol bilgileri
- Sunum hedefi

## 2) Problem ve Hedef
- IK surecindeki ana problemler
- Bu projede neyi cozdigumuz

## 3) Cozum Ozeti
- Auth/RBAC
- ATS + CV pipeline
- Matching + Interview + Scoring + AI evaluation

## 4) Mimari Diyagram
- Web, API, DB, Storage, LLM
- Veri akisi ve entegrasyon sinirlari

## 5) CV Pipeline + Matching
- Upload/parse/profile
- Job weights ve shortlist reasons/gaps

## 6) Interview (Adaptive) + Guardrails
- OFF/ASSIST/ADAPTIVE farklari
- Strict schema, allowlist, sensitive block, fallback

## 7) Scoring + Human Override
- Auto score
- Insufficient evidence kurali
- Human override ve history

## 8) Guvenlik/Uyumluluk + Audit
- Permissions
- Secrets, rate limit, headers
- Audit log + correlation id

## 9) Test/CI + Release Readiness
- Integration test kapsami
- Migration/vulnerability gate
- Docker compose prod-benzeri kurulum

## 10) Demo Akisi + Kapanis
- 10 dakikalik demo adimlari
- Sonuc, kisitlar, sonraki adimlar
